# Examples

| File                | What it is                                                                                                                                                                                                                                                                                                                                |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `kg3d-atlas.html`   | **Standalone showcase.** A complete 3D knowledge-graph explorer in one file — hand-written WebGL2, no dependencies at all. Open it directly in a browser: 700-node graph, Louvain communities, centrality ranking, focus-and-dim, legend isolation and shortest-path tracing. This is the same page published as the kg3d Atlas artifact. |
| `standalone.html`   | **Minimal embed.** The smallest possible use of `@kg3d/core` from a CDN, with a hand-written nine-node graph. Start here when integrating.                                                                                                                                                                                                |
| `sample-graph.json` | 220-node / 329-edge example graph in the wire format. Point the service's `json` adapter at it, or load it with `StaticAdapter`.                                                                                                                                                                                                          |
